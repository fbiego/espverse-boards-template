# ESPverse Boards Template

This PlatformIO project contains board profiles for ESPverse-supported devices.

A specific template can be created at [espverse.com/templates/boards](https://espverse.com/templates/boards). That generator strips out everything except the boards you choose, leaving a smaller project tailored to the selected hardware.

Browse the full ESPverse board catalog at [espverse.com/boards](https://espverse.com/boards).
